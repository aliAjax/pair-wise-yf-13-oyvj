# hxyfront-62001 船舶轮机值班记录

源提示词编号：1

我想做一个面向船舶轮机值班的前端记录系统，轮机员可以记录主机转速、滑油压力、冷却水温、燃油消耗、舱底水状态和异常巡检项。页面需要有值班班次切换、机舱参数看板、异常记录时间线、交接班摘要和按设备筛选的历史记录。数据先保存在浏览器本地，后续方便扩展成船队统一管理。

## 舵机试验与隔离台

值班页已扩展出"舵机试验与隔离台"（页签入口，默认打开），预置左、右两台舵机与自动、随动、应急三种操作方式：

- 隔离 / 恢复 / 复测均需登记班次、责任人、左右满舵角度与到位时间；同一台舵机有待复核申请时禁止重复提交
- 复核时按规则自动判定：实测角度不足 35°、左右到位时间差超过 5 秒或责任人未写清，则保持隔离并在台账列出不合格项
- 应急操舵可随时先接管；自动、随动须隔离解除且复测通过后才能选回
- 交接摘要自动列出未解除设备与卡住的复测项；记录保存在浏览器本地，离开页面后仍在

代码按职责分开维护：

- `src/steering/rules.ts` — 判断规则（角度 / 时间差 / 责任人阈值与操作方式选回限制）
- `src/steering/ledger.ts` — 试验台账（数据模型、localStorage 持久化、种子记录）
- `src/steering/SteeringConsole.tsx` — 页面入口（舵机卡片、登记表单、交接摘要、台账列表）
